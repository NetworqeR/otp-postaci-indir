# OTP Postacı — İndirme

Telefona gelen SMS'lerdeki doğrulama kodlarını (OTP) Gmail üzerinden e-posta adreslerine ileten Android uygulaması.

## İndir

**[OtpPostaci-1.0.apk](https://github.com/NetworqeR/otp-postaci-indir/releases/latest/download/OtpPostaci.apk)**

Bu link her zaman en son sürümü indirir.

## Kurulum

1. APK'yı telefona indirip açın. "Bilinmeyen kaynaklardan yükleme" uyarısına izin verin; Play Protect uyarısında **Yine de yükle** deyin.
2. Uygulamayı açıp SMS izni verin. Android 13 ve üstünde izin gri görünürse: Uygulama bilgileri → ⋮ → **Kısıtlanmış ayarlara izin ver**.
3. Ayarlar ekranı: Gmail adresi, 16 harfli uygulama şifresi (https://myaccount.google.com/apppasswords), alıcı adres → **Test maili**.
4. Pil kısıtlamasını kaldırın (Xiaomi'de ayrıca "Otomatik başlatma"yı açın).
